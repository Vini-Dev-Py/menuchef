# Protótipos

Demos em HTML para ver se a ideia de layout se sustenta. Não são o produto.

Suba um servidor na pasta `docs/pesquisa/design`:

```bash
python3 -m http.server 8765
```

| Demo | O que valida |
| --- | --- |
| [cardapio/](cardapio/) | Card, barra de categorias grudada, scroll spy, skeleton |
| [sacola/](sacola/) | Ponto que vai até o ícone, folha de baixo |
| [checkout/](checkout/) | Passos, entrega ou retirada, pagar agora ou na hora |
| [painel/](painel/) | Kanban e troca de filial |
| [landing/](landing/) | Primeira tela do SaaS |

A paleta é a Brasa clara: `#C2410C`, `#FFFBF5`, `#1C1917`, `#44403C`, `#F59E0B`. Prints desta rodada ficam em [screenshots/](screenshots/).
