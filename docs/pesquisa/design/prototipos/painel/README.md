# Protótipo do painel

HTML estático.

```bash
python3 -m http.server 8765
```

Abra `http://127.0.0.1:8765/prototipos/painel/` a partir de `docs/pesquisa/design`.

Quatro colunas do fluxo. O botão do cartão manda o pedido para a coluna seguinte. O seletor troca a filial e a fila. O botão Skeleton cobre o texto dos cartões.
