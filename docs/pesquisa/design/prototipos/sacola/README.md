# Protótipo da sacola

HTML estático.

```bash
python3 -m http.server 8765
```

Abra `http://127.0.0.1:8765/prototipos/sacola/` a partir de `docs/pesquisa/design`.

Adicionar solta um ponto até o ícone da sacola e soma a quantidade. O botão Sacola abre a folha de baixo. Escape e o fundo fecham. Com `prefers-reduced-motion: reduce` não há voo, só a contagem. `?auto=1` dispara um clique sozinho para o teste.
